# MisterGoodBeer – informações e avaliação para Brasil

## Dados e funcionalidades do MGB

| Informação / recurso | Descrição | Bom para Brasil? |
|---------------------|-----------|-------------------|
| **Preços por tipo de bebida** | Chope, long neck, lata, garrafa; preço por unidade/volume | ✅ Essencial. Mesma lógica (chope, long neck, lata) já existe no app. |
| **Happy hour** | Horários e detalhes de promoção | ✅ Muito usado. Manter e destacar. |
| **Categorias de bebida** | Cerveja, sidra, coquetel, pastis, vinho | ⚠️ Cerveja é o foco. Depois: coquetel (caipirinha) e vinho. Sidra/pastis menos prioritário. |
| **Filtro “Bar reservável”** | Lugares onde dá para reservar mesa | ✅ Muito relevante (grupos, aniversários, jogos). Vale adicionar. |
| **Transmissão de futebol** | Bar que transmite jogos | ✅ Muito relevante. Diferencial forte no Brasil. |
| **Aviso “Preços não verificados”** | Indica preço adicionado por usuário | ✅ Já temos. Manter. |
| **Endereço completo** | Nome + endereço no detalhe do bar | ✅ Já temos. Manter. |
| **Tags no bar** | Ex.: “2 chopes”, “Terraço”, “X cervejas servidas” | ✅ Relevante. Terraço/área externa e quantidade de opções fazem sentido. |
| **Avaliação (rating)** | Nota do bar (ex.: 7,8) | ✅ Bom para Brasil. Adicionar quando tiver dados (comunidade ou parceiros). |
| **Status “Fechado / Aberto”** | Ex.: “FECHADO EM SEXTA-FEIRA” ou horário de funcionamento | ✅ Muito útil. Evita ir até o bar à toa. Prioridade alta. |
| **Como chegar** | Abre rota no mapa (Google Maps / Waze) | ✅ Já temos. Manter. |
| **Reserva de mesa** | Reservar direto no app em bares parceiros | ⚠️ Bom a longo prazo. Exige integração com estabelecimentos. |
| **Eventos** | Shows, comédia, festas, eventos no bar | ⚠️ Relevante (samba, forró, música ao vivo). Pode ser fase 2. |
| **Promoções exclusivas** | Descontos só para usuários do app | ⚠️ Depende de parcerias. Fase 2. |
| **“Estou aqui”** | Marcar que está no bar (check-in) | ⚠️ Útil para gamificação e confiança nos preços. Fase 2. |
| **Minha conta / Favoritos** | Salvar bares favoritos | ✅ Relevante. Adicionar quando tiver auth. |

## Resumo: o que priorizar no app para Brasil

**Já no app (manter / reforçar)**  
- Preços por tipo (chope, long neck, lata, etc.)  
- Happy hour com detalhes  
- Busca por endereço  
- Mapa com marcadores de preço  
- Aviso “preços não verificados” para conteúdo de usuário  
- Endereço completo e “Como chegar” (Google Maps)  

**Adicionar em seguida (boa ideia para Brasil)**  
1. **Transmissão de futebol** – Filtro “Transmite futebol” e tag no bar.  
2. **Bar reservável** – Filtro e tag “Aceita reserva” / “Reservável”.  
3. **Status aberto/fechado** – Horário de funcionamento ou aviso “Fechado hoje” / “Aberto agora”.  
4. **Tags** – Terraço, quantidade de cervejas no cardão, etc.  
5. **Avaliação (rating)** – Quando houver dados (usuários ou parceiros).  

**Fase 2 (depois)**  
- Reserva de mesa (integração com bares).  
- Eventos (shows, música ao vivo).  
- Categoria “Coquetel” / caipirinha.  
- Conta, favoritos, check-in “Estou aqui”.
